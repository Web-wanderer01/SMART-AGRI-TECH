🌱 SMART‑AGRI‑TECH
SMART‑AGRI‑TECH is an advanced agriculture‑tech platform designed to empower farmers with smart resource allocation, real‑time insights, and AI‑powered assistance. The goal is to maximize crop yield, reduce waste, and simplify access to government schemes and advisory services — all through a clean, mobile‑friendly, and immersive web experience.

✨ Key Features
- AI‑Powered Assistant
Multilingual query support with voice commands to help farmers interact hands‑free.
- Smart Resource Allocation
Tools for optimizing water, soil, and fertilizer usage.
- Real‑Time Advisory
Weather forecasts, crop health monitoring, and seasonal planning guides.
- Government API Integration
Direct connectivity with Krishi Department APIs for schemes, subsidies, and policy updates.
- Farmer Dashboard
Personalized analytics, booking history, and resource tracking.
- Community & Collaboration
Forums, farmer stories, and cooperative workspaces.
- Immersive UI/UX
3D backgrounds (Three.js, Spline), smooth scrolling (Lenis), and gaming‑style visuals.

🛠️ Tech Stack
- Frontend: React, Three.js, Lenis, Chart.js
- Backend: Node.js, Express, SQL (PostgreSQL/MySQL)
- Integration: Government APIs (Krishi Department, PAN AO Code)
- Testing: Playwright, MSW
- CI/CD: GitHub Actions, Docker
- Monitoring: Prometheus/Grafana

🚀 Getting Started
Prerequisites
- Node.js (v18+)
- PostgreSQL/MySQL
- Git
Installation
# Clone the repo
git clone https://github.com/Web-wanderer01/SMART-AGRI-TECH.git

# Install dependencies
cd SMART-AGRI-TECH/backend && npm install
cd ../frontend && npm install


Run Development Servers
# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm start
